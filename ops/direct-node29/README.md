В Git находятся только скрипты/шаблоны без паролей и приватных ключей.
`provision.py` не меняет существующие объекты; при сетевой ошибке мутации
нужно сначала перечитать состояние. Автоматические повторы допускаются только GET.

В используемом Xray gRPC и WS выдают предупреждения о deprecated-транспортах;
они сохранены по запросу владельца и по рабочему образцу. REALITY этой версии
по умолчанию требует клиентское ядро Xray не старше 26.3.27.
