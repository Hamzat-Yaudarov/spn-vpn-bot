## Покрытие

- Полные JSON/YAML-конфиги: 399 основных доменов и их поддомены.
- Обычные URI-подписки Happ/INCY: компактный профиль `SPN RU Direct`,
  162 домена, включая все перечисленные пользователем сервисы и основные
  российские банки. Схема `happ://routing/onadd/` совместима с обоими клиентами.
- Остальные маршруты, селекторы и балансировщики сохранены. Нового общего
  обхода по всем российским IP или всей зоне `.ru` нет.
- Новые DNS-правила Xray ограничены доменами сервисов; для них используется
  прямой DNS `77.88.8.8`. Исходные DNS-серверы для остальных запросов сохранены.
- В компактном профиле сохранены стандартные локальные IPv4-сети. Виртуальные
  диапазоны FakeDNS `198.18.0.0/15` и `240.0.0.0/4` не исключаются из VPN.

Это не гарантированный полный список разрешённых IP каждого оператора и не
скрытие факта включённого VPN от приложения. Приложения могут обращаться
к новым доменам или запрещать сам факт активного VPN-интерфейса.
