авторизованным пользователям Telegram. Новое пробное вступление стоит **10 ₽**:

Изменены только три значения master: `enable_owner_entry_pilot=false`,

Это **не запуск клиентской торговли VPN**: выдача VPN, счета за подписки/докупки,

Для их выпуска необходим отдельный согласованный этап. Режим runtime по-прежнему
staging, а не обещание готовности публичного VPN-бизнеса.

## Скорость

Для уже зарегистрированных пользователей с зафиксированным первым приглашением
обычная навигация читает проект/регистрацию/роль одним свежим SELECT вместо
повторных обращений. Кеш прав, цен и денег не вводился. Новые/старые неполные
регистрации сохраняют прежнюю атомарную блокировку и проверку приглашения.

Служебное подтверждение кнопки Telegram больше не задерживает выдачу видимого
экрана. Повторные чтения списка подписок/счёта в одном действии устранены.
Финансовые проверки не пропускаются; чтения оставлены последовательными для
совместимости с односоединительными портами. Ускорение всех оплат вдвое и
конкретное время ответа клиента Telegram пока не заявляются.

Read-only замер до установки: SELECT median ≈535 мс, возврат соединения ≈268 мс.
Это объясняет значимость устранённых round trips, но не равно Telegram end-to-end.

После установки проверен эквивалентный read-only путь существующего владельца:
два прежних SELECT — median **1065,06 мс**, новый общий SELECT — **532,91 мс**,
ускорение **2,00×**, по три замера. Вызовов регистрации/обработчика webhook не было;
транзакция запрещала записи. Время сети и показа сообщения Telegram сюда не входит.

## Помощь администратора

После `/start` у администратора в управляющем боте появляется
«🛠 Проекты партнёров» → отдельный `/partners/support`.
Разрешены название, цена от 199 ₽, тексты/цвет бренда, поддержка и новости.
Изменения и аудит фактического администратора фиксируются одной транзакцией;
владелец проекта не подменяется. Защита версии запрещает затирать чужое изменение.

Глобальный доступ проверяется **только токеном центрального управляющего бота**
и списком операторов, не токенами партнёров: владелец партнёрского токена способен
сам подписывать его initData. Обычные workspace API остаются tenant-scoped.
Нет поддержки бесплатной выдачи, изменения владельца/команды/статусов,
доступа к токенам, выводам и чужим финансовым операциям через этот раздел.

Миграция `public_entry_trial.sql` применена в **SPN franchise**, не в базе SPN.
Она расширяет только допустимую цену вступления: 9990/10 ₽. Сохранены уникальность,

после миграции подтверждены один проект и один прежний заказ вступления.

Прежние master/units находятся в закрытом каталоге
`/etc/spn-partner-private/public-entry-before-20261025-bb1171417098`.
При ошибке установщик возвращает прежний закрытый доступ **с новым кодом**:
старый бинарный release не принимает расширенную SQL-проверку цены. Нельзя
слепо откатывать только бинарники либо сужать SQL constraint после появления
реальных публичных заказов по 10 ₽. Уже созданные счета сохраняют свою сумму.
