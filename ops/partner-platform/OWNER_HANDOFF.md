# Ввод секретов владельцем — выполнено

Пункты ниже **уже выполнены владельцем**. Повторять настройщик/менять пароль роли
не нужно: это нарушит действующее подключение без синхронного обновления master.
HTTP/manager работает на `92.42.102.103` через `https://partners.wayspn.online`;
доступ только ID `6910097562`. Владелец подтвердил открытие в Telegram.
Продажи/worker выключены. Основной SPN не менялся. Следующий этап — отдельный
тестовый магазин ЮKassa и изолированная выдача, без настоящих списаний.
Ниже сохранён порядок первоначальной настройки. Пароли/токены/JSON в чат не присылать.

## 1. Домен

В зоне **wayspn.online** добавить только:

```text
A partners → 92.42.102.103
```

Записи `@`, `sub`, `panel` и остальные оставить как есть. Сертификат и закрытый
backend подключаются после проверки DNS. Wildcard пока не требуется.

## 2. Пароль отдельной роли Supabase

В личном терминале подключиться к VPS:

```sh
ssh root@92.42.102.103
```

Клиент PostgreSQL уже установлен. Подключиться к **SPN franchise**, не к SPN:

```sh
psql -X -W --set=HISTFILE=/dev/null \
  "host=aws-0-ap-northeast-1.pooler.supabase.com port=5432 dbname=postgres user=postgres.crrmaqiakrqpfvhiwtkq sslmode=verify-full sslrootcert=/etc/spn-partner-ca/supabase.crt"
```

CA уже установлен по официальной ссылке из кабинета Supabase; проверка цепочки
и имени pooler на VPS прошла. Не менять `verify-full` на `require`/`disable`.
На `Password` ввести сохранённый пароль БД **SPN franchise**. Затем по очереди:

```text
SET password_encryption = 'scram-sha-256';
\password spn_partner_runtime
ALTER ROLE spn_partner_runtime LOGIN;
\q
```

На два скрытых запроса `\password` задать новый отдельный пароль от 16 символов
и сохранить его у себя. Не использовать пароль VPS или административный пароль.
Если исходного пароля БД нет, сначала сообщить об этом без секретов — команда
не должна подключаться к основной базе или отключать проверку сертификатов.

## 3. Токен управляющего бота

В том же SSH-терминале:

```sh
cd /opt/spn-franchise-staging/releases/20261021-5fab5be5cb97
.venv/bin/python scripts/partner_setup.py --config /etc/spn-partner-private/staging.json
```

Ввести ID `6910097562`, новый пароль роли из шага 2 и токен
**@spn_franchise_bot** из BotFather. Пароль и токен скрыты при вводе.
Файл создаётся с правами 0600 в root-only папке; сеть и продажи остаются выключены.
Не повторять настройку поверх существующего файла и не менять созданные ключи.

После сообщения «Конфигурация сохранена» написать в чат только **«готово»**.
Далее выполняются проверка доступа к отдельной БД, HTTPS и закрытый запуск.
