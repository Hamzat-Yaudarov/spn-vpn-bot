## Что установлено

- Только мониторинг пяти явно выбранных UUID из `install_ro_monitor.py`.
- `spn-controller-health.timer`: новый цикл через 120 секунд после завершения
  предыдущего. Каждый цикл обновляет конфигурации из панели и выполняет
  настоящий HTTPS-запрос через каждый VPN, а не проверяет только порт.
- Непривилегированный пользователь `spn-failover`, закреплённая версия Xray,
  ограниченный SSH-воркер. Токен панели и клиентские ключи в приватных файлах.
- Финансовая служба **не установлена и не включена**. Покупок и удалений IP
  при установке мониторинга нет. Обходы, CDN и VK-реле исключены.

Состояние на российском VPS:

```sh
systemctl status spn-controller-health.timer --no-pager
systemctl show spn-controller-health.service -p Result -p ExecMainStatus
cat /var/lib/spn-ip-failover/latest.json
```

`inactive` у успешно завершившейся службы `Type=oneshot` нормально;
постоянно активным должен оставаться таймер. Снимок `latest.json` содержит
только UUID и результаты, без ключей. Файл `routes.json` приватный — его не
копировать в чат. Один `down` не доказывает блокировку в РФ.

Остановка только мониторинга:

```sh
systemctl disable --now spn-controller-health.timer
systemctl stop spn-controller-health.service
```

## Подготовленные ограничения автопокупок

- Общий валовой лимит: 3 000 ₽ за календарные сутки Europe/Saratov.
- Месячная цена одного IPv4: не более 300 ₽.
- Не более десяти покупок на VPS до явного сброса оператором.
- Возвраты не пополняют дневной лимит и не обнуляют счётчик покупок.
- Неподтверждённый платный запрос не повторяется; нужна сверка.
- Только обычный дополнительный IP из пула. «IP на выбор» не заказывается.

Форма 1CENT проверена без покупки: 100 ₽/месяц, точная сумма за остаток
периода рассчитывается заново перед каждым заказом. Она не зафиксирована
в коде. Проверка цены и резерв общего бюджета предшествуют единственному
разрешённому платному запросу. Service Workers в браузере отключены,
чтобы сетевой предохранитель видел запросы формы.

## Что требуется перед включением денег

1. Повторно сверить хост → нода → услуга → назначенные IP. Нельзя считать,
   что UUID из двух списков соответствуют по порядку. Текущий адрес читается
   заново, а `ip_at_enrollment` — лишь снимок, не источник истины.
2. Однократно настроить на каждом из пяти VPS ограниченный сетевой помощник
   с резервной копией ifupdown. Передать управление от **доказанно своего**
   `spn-reality-source-*.service`, иначе старый исходящий IP вернётся после
   перезагрузки. Сеть и VPN при этом не перезапускаются.
3. Проверить независимый выход вне РФ и вход в 1CENT с постоянного контроллера.
4. Проверить один реальный цикл с известной ценой: заказ, назначение,
   VPN-проверка, переключение, откат/освобождение. После этого включать службу.

Проверка `managed_guest check` перед **каждым** заказом не меняет сеть,
не продолжает незавершённую операцию и блокирует покупку при неподготовленном
VPS или несовпадении снимка. Тест из одной российской сети не гарантирует
доступность во всех мобильных сетях.

Установочный root-ключ временный: удалить точную добавленную строку после
завершения настройки. Для рабочих проверок используется другой ключ с
принудительной командой; произвольный shell ему не разрешён.
