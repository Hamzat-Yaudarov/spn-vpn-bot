# Бесплатное продление Happ / INCY

Включено 6 октября 2026 года на VPS бота, каталог `/root/spn-vpn-bot`.
Remnawave остаётся на отдельном сервере. Для этой установки панель не обновлялась.

## Установка

- Установлены семь файлов, перечисленных в `manifest.json`.
- Базовые версии рабочих файлов и шесть зависимостей совпали с проверенными
  локальными версиями; несвязанные файлы не заменялись.
- `.env` сохранился без изменений, новых миграций БД нет, nginx не менялся.
- Резервная копия приложения и настроек подписок:
  `/root/spn-before-renewal-3ozioor8`.
- Пакет на сервере: `/root/spn-renewal-stage-z6731fv5`.
- Сервис `spn-bot` работает, `/health` подтверждает доступность бота, `/renew`
  и оба файла страницы возвращают HTTP 200.

Первоначальная установка прервалась на таймауте остановки до изменения файлов.
Следующая остановилась из-за статуса systemd `failed` после завершения процесса;
файлы также не менялись. Бот был возвращён в работу после каждой попытки.
В установщике увеличено время ожидания остановки до 180 секунд, добавлено
восстановление при ошибке остановки и разрешён завершённый статус `failed`.
Оба случая проверены локально, после чего установка завершилась успешно.

## Настройки подписки

Изменены только `customResponseHeaders` в настройках Remnawave:

- `profile-web-page-url`: `https://wayspn.ru/renew#{{SUBSCRIPTION_URL}}`.
- `announce`: подсказка для Happ / INCY и предупреждение про «ОБХОД».
- `announce-url` удалён: он создавал дублирующую кнопку «Канал/Бот» в INCY.

Сохранены `jjjj`, `support-url`, `profile-title`, `profile-update-interval`.
Удалён старый `sub-expire-button-link`, указывавший на посторонний пример
`https://t.me/GPT4Telegrambot`. Другие настройки, правила ответа, ограничения
устройств и маршрутизация сохранились.

Полные снимки настроек до и после находятся в закрытой резервной папке на VPS:
`subscription-settings-before.json` и `subscription-settings-after.json`.

## Проверки

- 63 теста API продления и обработки платежей, 6 браузерных сценариев.
- Живой сайт показывает правильные подписки: две подписки администратора,
  обычную и истёкшую. Тип тарифа соответствует выбранной подписке.
- Две подписки одного владельца используют разные индивидуальные ссылки.
- Запросы подписки с User-Agent Happ / INCY возвращают HTTP 200, раскрытую
  ссылку продления, объявление в Base64 и прежнюю поддержку. Использован
  существующий HWID; новое устройство для проверки не добавлялось.
- Проверена фактическая ссылка `subscriptionUrl` из панели. На этом сервере
  публичные подписки используют путь `/<shortUuid>`.
- Содержимое страницы и её assets соответствует установленным файлам.
- Без ссылки API возвращает HTTP 401. Страница/API не кешируются, страница
  имеет `Referrer-Policy: no-referrer` и CSP с ресурсами только своего сайта.

Реальные приложения Happ / INCY не запускались. Реальная оплата не проводилась,
счета не создавались. Premium не подключался и не оплачивался.

Пользователю нужно обновить подписку в приложении: в Happ переход через ⓘ слева
от трафика, в INCY — через «🌐 Сайт». Далее открывается продление этой подписки.

## Удаление дублирующей кнопки

6 октября 2026 года пользователь подтвердил, что `announce-url` отображается
в INCY как «Канал/Бот» и ведёт на ту же страницу. Из рабочей настройки удалено
только это поле; ссылка сайта, объявление, поддержка и остальные настройки
сохранены. Настройка повторно прочитана через API. Перезапуск бота не требуется.
Клиенту нужно обновить подписку, чтобы получить новые заголовки.

Снимок настроек перед этой коррекцией:
`/private/tmp/wayspn-incy-button-before-zor50dlo.json` на локальном компьютере.
Генератор и готовые JSON-файлы также больше не добавляют `announce-url`.
Восемь тестов заголовков и хранения прошли. Повторные HTTP-запросы подписки
с User-Agent INCY / Happ вернули 200 без `announce-url`, с правильной индивидуальной
ссылкой продления, прежней поддержкой и объявлением. Использован существующий HWID.
