# Way SPN — обзор двух тарифов

Вертикальный сравнительный ролик 1080×1920 для Instagram Reels, TikTok и YouTube Shorts.

## Важный статус оффера

Ролик использует объём антиглушилки **200 ГБ на 30 дней**, соответствующий текущей конфигурации проекта.

**Не публиковать ролик**, пока одновременно не выполнены условия:

1. версия с лимитом 200 ГБ развёрнута на сервере;
2. Remnawave выдаёт пользователю соответствующий лимит;
3. тариф и условия проверены тестовой покупкой;
4. описание публикации также обновлено на 200 ГБ.

Обычный тариф сформулирован как «без заданного лимита трафика по тарифу» — без обещаний абсолютной безлимитности инфраструктуры или скорости. Число устройств обозначено как включённое в базовый тариф, поскольку дополнительные устройства можно докупить отдельно.

## Материалы

- `output/way-spn-tariffs-overview-v1.mp4` — готовый мастер;
- `output/way-spn-tariffs-overview-v1.jpg` — обложка;
- `assets/overview-v1/scene-01.png` … `scene-04.png` — контрольные сцены;
- `audio/voice-overview-v1.aiff` — локальная озвучка macOS;
- `voice-script.txt` — текст диктора;
- `timings.json` — параметры и оффер;
- `render_ad.py` — редактируемый генератор.

## Сборка

```bash
say -v Milena -r 185 -f voice-script.txt -o audio/voice-overview-v1.aiff
python3 render_ad.py
```

Требуются пакеты из `requirements.txt`. Озвучка создаётся локальным системным голосом и не отправляет текст оффера во внешний сервис.
