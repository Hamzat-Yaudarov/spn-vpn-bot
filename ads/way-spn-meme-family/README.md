# Way SPN — мем-карусель «чисто для себя»

Нативный TikTok-формат: сначала бытовая шутка, затем переписка и реакция, а тариф появляется только в развязке. Никакой фирменной заставки, диктора или кнопки «купить».

## Готовые материалы

- `output/carousel/slide-01.jpg` … `slide-04.jpg` — основной формат фото-карусели;
- `output/way-spn-family-meme-v1.mp4` — видеоверсия 9,6 секунды;
- `output/way-spn-family-meme-cover-v1.jpg` — обложка;
- `caption.txt` — подпись к публикации;
- `assets/source/cat-calculator-v1.png` — оригинальная реакционная фотография, созданная специально для этого поста;
- `generation-prompt.txt` — точный запрос к встроенной генерации изображений;
- `render_post.py` — редактируемый генератор слайдов и видео.

## Публикация

Предпочтительный вариант — загрузить четыре JPG как TikTok photo post и выбрать внутри TikTok актуальный спокойный или ироничный звук. MP4 нужен для Reels/Shorts или для предварительного просмотра.

Русский текст оставлен намеренно. Подача под чеченскую аудиторию строится вокруг узнаваемой семейной ситуации и географии размещения, без искусственного акцента, флагов, гор, религиозных символов или обращений «для своих».

## Сборка

```bash
PYTHONPATH=/path/to/imageio-ffmpeg python3 render_post.py
```

Перед публикацией проверить на реально развёрнутом сервере цену, лимит устройств и условия обычного тарифа.
