# Ролики для конкурса Way SPN

Два черновика для согласования конкурса. В каждом ролике четыре сцены за 19,2 секунды. Размер кадра 1080 × 1920, частота 30 кадров/с. Текст читается без звука. Графика, анимация и инструментальная дорожка собраны кодом.

- **20 000 рублей** — акцент на первом месте. Файлы начинаются с `way-spn-contest-first-prize`.
- **Вместе на связи** — акцент на приглашении друга. Файлы начинаются с `way-spn-contest-with-a-friend`.

В `output/` находятся MP4, отдельные обложки JPG и общий предпросмотр `way-spn-contest-preview.jpg`. Оба ролика показывают десять призовых мест, условия получения приза и путь вступления через бота. Перед публикацией сверьте формулировки с правилами конкурса и заполните дату окончания в `content.json`.

В подпись к ролику добавьте ссылку на участие из команды `/contest_preview`. Команда `/contest` в боте открывает карточку действующего конкурса.

## Сборка на macOS

```bash
bash ads/way-spn-contest/render.sh
```

Понадобятся Swift из Xcode Command Line Tools и FFmpeg с кодировщиками H.264 и AAC. Скрипт использует FFmpeg из `PATH` либо из зависимостей соседнего проекта `source-code-pilot`. Можно указать другой исполняемый файл через `FFMPEG_BIN`. Для дополнительных версий доступны `CONTEST_COPY` и `CONTEST_OUTPUT`.

Тексты, ник бота и подпись даты хранятся в `content.json`. При запуске дополнительной версии используйте короткие подписи и проверяйте, как они читаются в итоговом кадре. Монтаж, векторная графика и музыка определены в `render.swift`.
