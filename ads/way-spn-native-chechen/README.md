# Way SPN — нативный ролик для чеченской аудитории

Спокойный вертикальный ролик 1080×1920 для Reels, TikTok и YouTube Shorts. Он начинается с повседневных ситуаций — сообщение домой, рабочий ответ и связь в дороге. Бренд и тарифы появляются только после десятой секунды, без большой кнопки и призыва «купить сейчас».

Основной язык — русский. Чеченские фразы намеренно не используются без проверки носителем: локальность лучше задавать размещением и естественным автором, а не имитацией речи или этническими клише.

## Материалы

- `output/way-spn-native-chechen-ru-v1.mp4` — мастер 19,2 секунды;
- `output/way-spn-native-chechen-ru-v1.jpg` — обложка;
- `assets/native-ru-v1/scene-01.png` … `scene-04.png` — контрольные кадры;
- `audio/voice-native-ru-v1.aiff` — локальная озвучка macOS;
- `voice-script.txt` — текст диктора;
- `publishing-copy.md` — подписи и правила подачи;
- `timings.json` — тайминги и условия тарифов;
- `render_ad.py` — редактируемый генератор.

## Сборка

```bash
say -v Milena -r 166 -f voice-script.txt -o audio/voice-native-ru-v1.aiff
PYTHONPATH=/path/to/imageio-ffmpeg python3 render_ad.py
```

Озвучка создаётся локальным системным голосом: текст оффера не отправляется во внешний сервис.

## Проверка оффера

В конфигурации проекта указано 200 ГБ для базового тарифа с антиглушилкой. Перед публикацией всё равно нужно проверить реально развёрнутый сервер и пройти тестовую покупку, чтобы экран ролика совпадал с тем, что получает пользователь.
